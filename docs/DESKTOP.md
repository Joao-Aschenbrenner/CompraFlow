# Desktop

O CompraFlow possui uma versão Electron para Windows que inicia o backend Spring Boot automaticamente em `127.0.0.1`, mantém os dados em H2 persistente e empacota um JRE 21 junto ao aplicativo.

A interface permite operar fornecedores, solicitações, cotações, avaliação por Strategy e aprovação/rejeição. O release de teste é publicado como `v1.1.0-desktop` em formatos Installer e Portable.
