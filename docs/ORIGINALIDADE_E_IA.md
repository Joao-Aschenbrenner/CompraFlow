# Originalidade e uso de IA

## O que foi feito de forma diferente do laboratório

O exemplo de referência do curso trabalha com clientes, endereços e consulta de CEP. O CompraFlow usa outro domínio e outros casos de uso:

- solicitações de compra;
- itens solicitados;
- fornecedores;
- propostas/cotações;
- algoritmos de escolha;
- níveis de aprovação.

Os Design Patterns são os mesmos conceitos ensinados no curso, mas aplicados a problemas diferentes.

## Uso de IA

IA foi utilizada como ferramenta de apoio para:

- discutir a ideia do projeto;
- estruturar classes e responsabilidades;
- revisar código;
- gerar cenários de teste;
- organizar documentação.

Antes de enviar para avaliação, recomenda-se:

1. executar todos os testes;
2. fazer pelo menos uma alteração pessoal pequena no README ou em uma regra;
3. percorrer o Swagger manualmente;
4. saber explicar Singleton, Strategy, Facade e Chain of Responsibility;
5. não afirmar que uma parte foi testada se ela ainda não foi executada localmente.
